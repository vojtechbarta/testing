# Plan archive

Checked-in copies of implementation plans for long-term reference (PRs, onboarding, design history).

**Naming:** `YYYY-MM-DD-short-topic.md` (chronological sort in Git).

**Source:** Plans are drafted in Cursor (e.g. Create Plan); when a plan is agreed, save the markdown body here using the naming convention above.

Agent rule: `.cursor/rules/plan-archive-docs.mdc` (ensures finalized plans are copied here with the naming convention above).
